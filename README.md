# 🚗 Car Racing Game

एक exciting 3D-style racing game Python और Pygame में बनाया गया है!

## 🎮 Features

- ✅ Smooth car controls (Arrow keys)
- ✅ Obstacles to avoid
- ✅ Score & Level system
- ✅ Multiple difficulty levels
- ✅ High score tracking
- ✅ Collision detection

## 📋 Requirements

```bash
pip install pygame
```

## 🚀 कैसे चलाएं?

```bash
python main.py
```

## 🎯 Game Controls

- **↑ Arrow Up** - Car को आगे move करो
- **↓ Arrow Down** - Car को पीछे move करो
- **← Arrow Left** - Left में move करो
- **→ Arrow Right** - Right में move करो
- **SPACE** - Pause/Resume
- **ESC** - Game बंद करो
